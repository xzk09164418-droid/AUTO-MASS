# 通用脚本精简与 MaaEnd 迁移

本机构建仅注册通用脚本。本次移除了无运行入口、无在役调用者的专项调度器、自动代理、更新器和前端编辑页面；活动内容、社区签到、计划、历史记录或共享工具仍引用的模块继续保留。生成的 API 类型未手工修改。

## MaaEnd

- 现存 `MaaEndConfig` 在加载前迁移为 `GeneralConfig`，脚本 ID、用户 ID 和队列引用保持不变。
- 写入前保存原始配置；备份失败不改原文件，重复启动不重复迁移。
- 运行入口：`MaaEnd.exe --autostart --quit-after-run`，使用源程序的原生自动执行配置。需要固定实例时，可在通用脚本参数中添加 `--instance "实例名"`。
- 设置入口：无参数打开 `MaaEnd.exe`，不会继承自动执行参数。通用脚本参数中的第二入口允许 `%` 后为空。
- 配置编辑入口指向 `config/mxu-MaaEnd.json`，沿用原生文件编辑的版本检查和备份机制，不转换或覆盖其内部字段。
- 原专项的游戏任务选项、账号切换、快速配置和专项计划不再执行，应在 MaaEnd 自身设置中维护；原专项配置和已保存的原生文件仍留在备份中。通用脚本未配置日志规则时按进程结束判定，不能将其等同于原专项逐任务统计。

本机原 MaaEnd 配置已从此前的 `config/general-only-backup` 恢复，并恢复缺失的队列项，不覆盖其他通用脚本。操作前另存 `config/maaend-general-backup-*`。路径按用户要求保持 `C:\script\Maaend`；参考安装 `C:\script\MaaEnd-win-x86_64-v2.27.0` 的 `--help` 已验证上述 CLI。未移动安装目录，目标路径不存在时无法直接运行，须先将程序准备在指定路径。

## 界面与验证

脚本列表移除类型标签，名称由 18 px 调整为 20 px，在名称区域水平居中并允许换行；窄屏字号同步增大。

本次迁移契约、空参数设置入口、类型检查、全量 lint、浏览器与宿主构建通过。9 项隔离端到端测试通过，覆盖原生配置读写、队列执行/取消、WebSocket 重连、外部占用、保留联网能力和深浅色的 1K–4K、16:9/16:10 布局。真实 MaaEnd 游戏任务没有执行。

全量前端单元测试尚有旧更新检查/更新执行、专项卡片预期和专项插槽超时失败；在改动前的提交快照中运行同样测试，也复现了这些失败。本轮移除了仅服务于被删除页面的测试，保留的描述对象合并测试改用独立测试对象。
