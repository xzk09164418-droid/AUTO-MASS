# 本机构建的联网范围

本构建不从上游拉取代码，不执行程序、Runtime、后端或脚本更新检查与下载。
这些限制固定在构建中，旧配置中的自动更新、遥测开关不会重新启用它们。

保留：

- 首页公开游戏活动、活动图片、活动关卡和活动提醒。
- 社区签到及所需账号登录、扫码认证、签到通知。
- QQ 邮箱指令、处理回执，以及用户配置的邮件、Webhook 等远程通知。
- 本机前后端、WebSocket、远程桌面宿主、热键、模拟器等本地通信。

停用：

- 自动和手动更新、启动时拉取源码、在线安装运行环境。
- Matomo 统计、Sentry 遥测、上游公告和远程游戏维护查询。
- 在线脚本模板、配置分享、在线主题/外观资源。
- 社区账号活跃度查询（社区签到保留）。

旧客户端访问停用的联网接口会得到明确的 403 停用响应，不会伪装成“已是最新版”。
本地配置编辑、导入、备份、队列、计划、日志、错误提示和通知保持原有行为。
已保存的账号、通知凭据、更新偏好等数据不删除，便于回退。

限制只针对 AUTO-MAS 本身，不修改系统防火墙、代理，也不干预外部脚本或游戏自己的联网。
用户主动在系统浏览器打开的链接仍由外部浏览器处理。

## 离线安装环境

已有环境可以继续使用。恢复到没有环境的电脑时，先通过离线安装包安装 Python 3.12 和
Node.js 22 或更高版本，再把对应 Windows/Python 版本的依赖 wheel 放进 `offline-wheels/`。
安装脚本使用 `--no-index --only-binary=:all:`，缺包会明确报错，不自动连接软件源。
也可以给 `scripts/install_backup_env.ps1` 传入 `-Wheelhouse <本地依赖目录>`。
登录自启配置流程保留。
