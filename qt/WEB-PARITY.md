# Qt 客户端与网页版的交互对照

逐页列出网页版（`frontend/src/views`）的可交互部分，以及在 Qt 客户端里的对应位置。
「条件」一栏是网页版里控件何时可用 / 何时出现，Qt 端按同样的规则联动（`Live.isOff` / `rowShown` / `opOff`）。

图例：✅ 已对应　◐ 部分对应　✗ 未对应（原因见备注）

拖动排序统一用暂存区（`SortDock.qml`、托管管理沿用「暂存录像卡」）：暂存区常态不显示，拖动的卡片进入范围时才用橙色小圆角框出。

## 托管管理（02）

| 网页版 | 条件 | Qt |
| --- | --- | --- |
| 脚本配置全部字段 | 脚本运行中整页锁定，结束后恢复 | ✅ 运行快照每 3 秒刷新，锁定时控件置灰、操作栏提示 |
| 游戏：启动方式切换 | 客户端 / 模拟器 / URL 各显示自己的字段 | ✅ |
| 模拟器下拉、实例 | 未选模拟器时实例不可用 | ✅ 实例为手动填写（网页版读不到设备时同样手填） |
| 进程追踪 | 开启后才显示进程名、路径、命令行 | ✅ |
| 账号：前后置脚本 | 开关开启后路径可用 | ✅ |
| 账号：通知 | 未启用通知时各渠道不可用 | ✅ |
| 原生配置编辑 / 打开源程序设置 | 运行中锁定 | ✅ |
| 新建 / 复制 / 删除脚本、添加 / 删除账号、Webhook | 运行中锁定 | ✅ |
| 搜索、拖动排序 | — | ✅ |
| 从模板创建脚本、上传分享配置 | 需联网模板库与分享授权 | ✗ 不接入 |
| 日志预处理 / 推送规则的结构化编辑、规则调试 | — | ◐ Qt 为原文编辑，无调试器 |
| 账号拖动排序 | 运行中锁定 | ✅ 拖动账号页签进暂存区，再拖回目标页签 |
