🚀 核心重构特性一览
已就绪
  • 本地远程桌面托盘化常驻：复用 BetterGI ChildSessionHost (WTSEnableChildSessions + MsRdpClient10 + Schedule.Service)，默认隐藏在系统托盘静默运行，避免主桌面干扰。
  • 包装器模式状态跟踪：通过 child_session_wrapper.py 在子会话内启动外部程序，实时采集 PID、运行状态与退出码。
  • 双模超时与 3 遍强杀清理：HardTimeLimit 作为从任务开始到结束（含全部重试）的总上限时间；保留有日志模式下的日志停滞超时 RunTimeLimit；到时或结束时强制执行 3 遍 taskkill /F /T。
  • 无日志模式与无配置回写：日志路径选填，留空时日志超时自动失效，在总上限时间内自行退出（不限返回码）即判成功；移除配置文件回写，纯靠外部程序启动参数控制启停。
  • 外部借用让渡与全局热键：相邻两个子任务间隔自动检查外部程序借用请求并让渡桌面，等待回传后继续；支持 Ctrl+Alt+S 启停、Ctrl+Alt+Left/Right 上/下一任务。
⚡ 快捷启动与无窗口命令行调用
前后端分离
除使用本 Web 控制台外，您也可以直接通过启动参数调用后端或控制程序直接无窗口运行，完全不弹出浏览器或远程桌面窗口：
# 1. 启动 Node.js 前端并调用系统浏览器（默认模式） Start-AUTO-MAS.bat # 2. 无窗口直接启动后端并自动运行默认队列（远程桌面托盘静默运行） Start-Headless.bat --auto-run python main.py --headless --run-queue first # 3. 命令行直接运行单个外部脚本（无日志模式 + 远程桌面包装器） python remote_script_controller.py run-script "C:\Tools\MyScript.exe" --args -c config.json --hard-timeout 60 --retries 3 # 4. 外部程序申请借用本地远程桌面 & 停止使用后回传 python remote_script_controller.py acquire-desktop --caller "OtherBot" --wait python remote_script_controller.py release-desktop --caller "OtherBot"
